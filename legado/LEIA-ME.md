# Site estático anterior (legado)

Esta pasta guarda o site como ele era antes da migração para Next.js (HTML + Tailwind via CDN + JavaScript puro),
**apenas para consulta**. Nada aqui é publicado: o site atual fica em `src/` (páginas, componentes e backend)
e as fotos e vídeos em `public/assets/`.

- O inventário do que este site fazia (e onde cada coisa está agora) está em `docs/INVENTARIO.md`.
- Os caminhos de imagens destes arquivos apontam para `assets/img`, que foi movido para `public/assets/img`;
  por isso, abertos direto no navegador, eles aparecem sem fotos.
